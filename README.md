# PalsBuild

Informações e ferramentas para jogadores de Palworld em pt-br!

## Instalação

Na pasta do projeto:

```powershell
python -m pip install -r requirements.txt
python manage.py migrate
```

## Executar

```powershell
python manage.py runserver
```

O endereço padrão é `http://127.0.0.1:8000/`.
