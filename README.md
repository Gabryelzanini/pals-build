# PalsBuild

Informações e ferramentas para jogadores de Palworld em pt-br!

## Instalação

Na pasta do projeto:

```powershell
python -m pip install -r requirements.txt
python manage.py migrate
```

## Executar

```powershell
python manage.py runserver
```

O endereço padrão é `http://127.0.0.1:8000/`

## Fontes externas

A base factual vem do PalworldOnline e é enriquecida pelo projeto `palworld-knowledge`. Conteúdos detalhados em português são obtidos do Palworld.gg por rotas internas do Django.

Consulte [DATA_SOURCES.md](DATA_SOURCES.md) para detalhes e atribuições.
